# Trash2Cash

A responsive Next.js presentation build for the eGovPH Hackathon flow.

## Start locally

```powershell
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Included flow

1. Citizen login
2. National ID e-Verify and Face Liveness
3. Recyclable photo capture
4. eGov AI estimate
5. Accredited MRF or junkshop selection
6. Physical weighing and validation
7. Cash or Green Points selection
8. GCash, Maya, bank, or points completion

The interface contains a self-contained presentation flow and does not require environment variables, a database, or external API credentials.
