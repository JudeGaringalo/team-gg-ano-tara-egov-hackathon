# eGovPay API Documentation

Base URL: `{{base_url}}`

## Authentication
All requests require the `X-eGovPay-Token` header set to your merchant API token. Use a `test_`-prefixed token while integrating — it runs in test mode and does not touch live financial networks.

---

## 1. Generate Payment

`POST {{base_url}}/api/v1/transaction`

Creates a payment transaction and returns a hosted payment-gateway link the customer can use to pay.

### Headers

| Header | Value | Required | Description |
|---|---|---|---|
| `X-eGovPay-Token` | `test_<TOKEN_KEY>` | Yes | Merchant API token. A `test_`-prefixed token runs in test mode. |
| `Content-Type` | `application/json; charset=utf-8` | Yes | Request body is JSON. |

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `items` | array | Yes | List of line items being paid for. |
| `items[].name` | string | Yes | Name of the item. |
| `items[].amount` | double | Yes | Amount of the item. |
| `amount` | double | Yes | Total transaction amount. |
| `settlement_template_uuid` | uuid | Yes | The settlement template used for bank settlements. |
| `redirect_url` | url | Yes | URL to redirect the customer to once payment has been processed. |
| `txnid` | string | Yes | The transaction ID generated by the biller/merchant. |
| `callback_url` | url | Yes | URL notified for every transaction status change. |
| `digest` | string | Yes | HMAC-SHA256 of the transaction, keyed by the API token: `hash_hmac('sha256', "$amount|$txnid", $token)`. |
| `currency` | string | No | Currency code, e.g. `PHP`. |
| `mobile` | string | No | Customer mobile number (used for the e-receipt). |
| `email` | string | No | Customer email. |
| `name` | string | No | Customer name. |
| `expires_at` | datetime | No | Transaction expiry, `YYYY-MM-DD HH:MM:SS`. |
| `link_expires_at` | datetime | No | Payment-link expiry, `YYYY-MM-DD HH:MM:SS`. |
| `description` | object | No | Additional transaction information. |

```json
{
  "amount": 1000,
  "settlement_template_uuid": "{{template_id}}",
  "currency": "PHP",
  "digest": "c5989a520055e65025a695bb1483b30b6cd7923c79c648fff5e757bbabc62fa2",
  "mobile": "09XXXXXXXXX",
  "expires_at": "2027-07-10 23:59:59",
  "callback_url": "https://localhost:8000/callback",
  "redirect_url": "https://localhost:8001/",
  "txnid": "TESTREF123",
  "link_expires_at": "2027-07-10 23:59:59",
  "email": "your@email.com",
  "name": "TEST",
  "items": [
    { "name": "Item # 1", "amount": 1000 }
  ]
}
```

### Example Request (cURL)

```bash
curl --request POST \
  --url '{{base_url}}/api/v1/transaction' \
  --header 'X-eGovPay-Token: {{api_token}}' \
  --header 'Content-Type: application/json; charset=utf-8' \
  --data '{
    "amount": 1000,
    "settlement_template_uuid": "{{template_id}}",
    "currency": "PHP",
    "digest": "c5989a520055e65025a695bb1483b30b6cd7923c79c648fff5e757bbabc62fa2",
    "mobile": "09XXXXXXXXX",
    "expires_at": "2027-07-10 23:59:59",
    "callback_url": "https://localhost:8000/callback",
    "redirect_url": "https://localhost:8001/",
    "txnid": "TESTREF123",
    "link_expires_at": "2027-07-10 23:59:59",
    "email": "your@email.com",
    "name": "TEST",
    "items": [
        { "name": "Item # 1", "amount": 1000 }
    ]
}'
```

### Responses

| Status | Description |
|---|---|
| 201 Created | Transaction created; hosted payment link returned. |
| 401 Unauthorized | Invalid API header/token. |
| 422 Unprocessable Entity | Validation failure (e.g. invalid digest). |

**201 Created**
```json
{
  "data": {
    "uuid": "a23977c3-f2f2-4e5c-bf53-94bcff48e49c",
    "url": "https://egovpay-pgi-dev.oueg.info/a23977c3-f2f2-4e5c-bf53-94bcff48e49c",
    "channel": {
      "refno": "0IOKUXQ5XX"
    }
  }
}
```

**401 Unauthorized**
```json
{
  "error": "invalid_api_header",
  "message": "Invalid API Header",
  "error_description": "Kindly double check your header and try again."
}
```

**422 Unprocessable Entity**
```json
{
  "error": "unprocessable_entity",
  "message": "The given data was invalid.",
  "error_description": "The given data was invalid.",
  "errors": {
    "digest": ["The digest is not valid."]
  }
}
```

### Notes
- The `digest` binds `amount` and `txnid` to your token — recompute it for every request.
- Use a `test_`-prefixed token while integrating so no live funds move.

## 2. Check Transaction Details

`GET {{base_url}}/api/v1/transaction/{{transaction_uuid}}`

Returns the details of a transaction by its `uuid`.

### Headers

| Header | Value | Required |
|---|---|---|
| `X-eGovPay-Token` | `test_<TOKEN_KEY>` | Yes |
| `Content-Type` | `application/json; charset=utf-8` | — |

### Path Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `uuid` | uuid | Yes | The transaction UUID returned when the payment was generated. |

### Example Request (cURL)

```bash
curl --request GET \
  --url '{{base_url}}/api/v1/transaction/{{transaction_uuid}}' \
  --header 'X-eGovPay-Token: {{api_token}}' \
  --header 'Content-Type: application/json; charset=utf-8'
```

### Responses

| Status | Description |
|---|---|
| 200 OK | Transaction found; returns full details. |
| 401 Unauthorized | Invalid API header/token. |
| 404 Not Found | Transaction not found. |

**200 OK**
```json
{
  "data": {
    "uuid": "a23977c3-f2f2-4e5c-bf53-94bcff48e49c",
    "refno": "0IOKUXQ5XX",
    "txnid": "TESTREF123",
    "environment_type": "TEST",
    "items": [
      { "name": "Item # 1", "amount": "1000" }
    ],
    "amount": "1000.0000",
    "system_fee": "0.0000",
    "channel_fee": "0.0000",
    "partner_fee": "0.0000",
    "currency": "PHP",
    "payment_status": "INITIAL",
    "payment_channel": null,
    "payment_channel_uuid": null,
    "payment_channel_branch": null,
    "callback_url": "https://localhost:8000/callback",
    "redirect_url": "https://localhost:8001/",
    "paid_at": null,
    "link_expires_at": "July 10, 2027 11:59:59 PM",
    "expires_at": "July 10, 2027 11:59:59 PM",
    "created_at": "July 10, 2026 05:51:01 PM"
  }
}
```

**404 Not Found**
```json
{
  "error": "transaction_not_found",
  "message": "Transaction not found",
  "error_description": "Transaction not found"
}
```

**401 Unauthorized**
```json
{
  "error": "invalid_api_header",
  "message": "Invalid API Header",
  "error_description": "Kindly double check your header and try again."
}
```

### Notes
- `payment_status` values seen so far: `INITIAL` (unpaid). Other statuses (e.g. paid/failed/expired) likely exist — confirm against full docs or the `callback_url` payloads when a transaction transitions.
- Fee fields (`system_fee`, `channel_fee`, `partner_fee`) are broken out separately from `amount`.

| Endpoint | Method | Purpose |
|---|---|---|
| `/api/v1/transaction` | POST | Create a payment transaction, get hosted payment link |
| `/api/v1/transaction/{uuid}` | GET | Check status/details of a transaction |
